# SS PLAY — OTT MVP

Professional mobile-first starter for SS Enterprises' OTT platform.

## Phase 1 included
- OTT-style responsive homepage
- Featured Movies and Web Series sections
- Sign-in UI placeholder
- Premium plan UI
- Video-player placeholder
- Legal/content-rights notice
- Mobile-first design
- No copyrighted/demo movie URLs included

## Phase 2
Connect:
1. Supabase Auth
2. PostgreSQL content database
3. Admin panel
4. Video storage/CDN
5. Secure playback URLs
6. Subscription/payment gateway
7. Ads
8. Watch history/watchlist
9. Analytics

## Legal rule
Publish only content for which SS PLAY has ownership, licence, permission, or another lawful distribution right. Keep a record of each title's rights, territory, duration, and permitted monetization.

## Deploy
This is a static site and can be deployed to Render Static Site, GitHub Pages, Netlify, etc.

For production streaming, do not use a basic public video URL as the final security model. Add authenticated/expiring playback and an appropriate video delivery provider in Phase 2.
